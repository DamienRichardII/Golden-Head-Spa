# Golden Head Spa

Application mobile native (Expo / React Native) + administration + Supabase. Voir `docs/PROJECT_STATUS.md`.

```bash
pnpm install
pnpm dev:mobile      # Expo
pnpm typecheck && pnpm test
```
Copier `.env.example` vers `.env` ; `EXPO_PUBLIC_PLANITY_BOOKING_URL` surcharge l'URL Planity par défaut.
